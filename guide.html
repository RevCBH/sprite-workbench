User Guide (M1)

M1 is client-only: load a clip, curate frames, export a bundle. No local API server is required.

1. Start

cd sprite-workbench
npm install
npm run dev

2. Main Workflow

  1. Upload a video (drag/drop or file picker).
  2. Curate timing and frames:
    set in/out, skip cadence, disable bad frames, tune keying, preview playback.
  3. Export Bundle from the header action.

3. Export Output

Bundle export writes a ZIP to your downloads folder containing:

  • <base>.png (sheet image)
  • <base>.atlas.json (atlas metadata)
  • <base>.sprite_frames.tres (Godot SpriteFrames text)
  • manifest.json (basic export metadata)

4. Controls

Timeline

  • Click frame: preview frame.
  • Double-click or D: enable/disable frame.
  • ← / →: step active frames.
  • Space: play/pause.

Range

  • I: set In frame.
  • O: set Out frame.
  • Skip Every N: stride through enabled frames.

Background Key

  • Toggle keying on/off.
  • Eyedropper to pick key color from preview.
  • Adjust tolerance, softness, despill.

5. GIF Export

Export GIF is for fast review and does not affect bundle export.

6. Roadmap

M1: client-only editing/export.
v1: optional adapter-based project mode, including server-backed workflows.

7. Troubleshooting

No frames after upload

Confirm the file is a supported video and retry with a shorter clip to isolate codec issues.

Export seems empty

Ensure at least one frame is enabled in range and that Start/End bounds include active frames.
